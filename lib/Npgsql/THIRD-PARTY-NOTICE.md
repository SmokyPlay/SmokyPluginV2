# PostgreSQL runtime dependencies

This directory contains Npgsql 4.1.14 and its .NET Framework 4.6.1 runtime
dependencies. At build time the framework dependencies are embedded into
`SmokyPluginV2.dll`; only `Npgsql.dll` remains a separate deployment file.
